# THE EDIT — Luxury Fashion Brand

THE EDIT is a modern luxury fashion website designed to showcase a premium and editorial brand identity.

## 🔗 Live Website
https://anjali-builds.github.io/THE-EDIT/


## ✨ Features

- Clean and elegant fashion-focused design
- Premium image and video presentation
- Minimal and sophisticated visual aesthetic
- Responsive and engaging layout

## 🛠️ Built With

- HTML5
- CSS3

## 🎯 Project Goal

The goal of this project was to create a sophisticated fashion brand website with a strong visual identity, focusing on clean layouts, premium presentation, and an engaging user experience.
